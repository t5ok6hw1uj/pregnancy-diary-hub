# 一次意外收获——产后哺乳期后恢复brasize

> 更新时间：2026-09-11 (UTC+8)

这真是一次意外收获，让产后三年多的我，恢复了产前的bra size

 -------------------------------------

相信很多经历过生产、哺乳期的宝妈们肯定都懂得，bra变得空空荡荡的感觉~

生孩子之前也只是听说过，有的人为了保持身材不会母乳喂养孩子，但真的没有想到，哺乳前和哺乳后会变化那么大，真的是从峰峦叠嶂变成了一马平川~

这可能和气血亏虚有关，每个人的情况都不一样，这也只是我的个人体验哈，但我相信，经历过的人都懂~

产后哺乳期期间，我的身体也不好，气血亏虚严重，再加上母亲病重，压力特别大，导致头疼特别严重，但是那时候经济困难，一直没有好好调理

一直到今年，实在是头疼的顶不住了，止疼药都停不了，没办法，最后硬着头皮去附近的理疗店做起了艾灸。一个套盒大概可以做16~17次，前期是隔一天做一次，后来就是隔两天做一次的节奏，大家可以自己算算时间

我是在第一个套盒快做完的时候，忽然发现bra好像变紧了，自从一马平川后，买的bra size 都比以前小了，后来我仔细观察了几天，发现胸部好像确实比以前大了，后来又坚持艾灸了几次，终于确定了，我好像快恢复到产前的size了

于是第一个套盒做完后，我就果断的又购买了一个套盒，继续调理

我做的艾灸，是全身做的那种，一次灸背面（从背到脚整体灸），一次灸前面（从腹部到脚整体灸），因为通常我们的身体是不通的，只灸一处的话，效果慢，而且不利于全身畅通，建议大家也选择全身灸

在去养生馆艾灸之前半年左右吧，我自己买了个在家艾灸的仪器，烟都可以排出去的那种，但是实操下来发现，因为身体不通，每次只能灸一处，效果不理想，也容易上火，就不在家自己折腾了，最后去的理疗店。

做艾灸的最初目的是想调理气血，希望气血好一些后可以缓解头疼的症状，没想到恢复了以前的bra size，还是挺意外的。有这样的效果，我考虑主要原因还是产后哺乳期后气血亏虚造成的，当气血补上来后，身体得到滋养，就开始慢慢恢复了，有同样情况的宝妈们也可以试一试
